# Telegram-бот для конкурсных списков

Бот отслеживает положение заявления в официальных списках поступающих. Каждое
отслеживание — точная связка страницы списка и ID заявления.

Поддерживаются:

- МГУ: предварительные и конкурсные страницы факультетов `cpk.msu.ru`, включая
  ВМК (`dep_02`) и мехмат (`dep_01`);
- МФТИ: существующий формат конкурсных таблиц.

Для МГУ бот рассматривает только основные бюджетные места в рамках КЦП. БВИ,
квоты, целевое и платное не учитываются. В итоговых списках используются
официальные значения основного высшего и высшего проходного приоритетов МГУ;
бот не прогнозирует зачисление самостоятельно.

Предварительная и конкурсная страницы являются разными источниками, а их ID
могут отличаться. После публикации конкурсных списков нужно добавить новое
отслеживание с ID, показанным на странице `/rating/`.

## Запуск через Docker

Требуются Docker Engine с Compose v2. Скопируйте пример конфигурации и замените
`BOT_TOKEN` и `DB_PASSWORD`:

```bash
cp .env.example .env
docker compose up -d --build
```

PostgreSQL запускается внутри Compose и не публикует порт на хост. Бот ждёт
успешного healthcheck базы, после чего сам создаёт таблицы `sources` и
`trackings`. Посмотреть состояние и логи:

```bash
docker compose ps
docker compose logs -f bot
docker compose exec db sh -c 'psql -U "$POSTGRES_USER" -d "$POSTGRES_DB"'
```

Обычная остановка сохраняет базу в именованном volume:

```bash
docker compose down
```

Полный сброс проекта вместе с данными PostgreSQL выполняется отдельно. Команда
необратимо удаляет отслеживания:

```bash
docker compose down -v
```

## Локальный запуск без Docker

Требуются Python 3.11+ и чистая база PostgreSQL.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env
python3 main.py
```

Переменные окружения:

- `BOT_TOKEN` — токен Telegram-бота;
- `DB_NAME`, `DB_USER`, `DB_PASSWORD`, `DB_HOST`, `DB_PORT` — PostgreSQL;
- `LOG_DIR` — необязательная папка логов;
- `ADMISSION_YEAR` — необязательный год кампании, по умолчанию текущий год по
  Москве.

Для локального запуска задайте `DB_HOST=localhost`. При первом запуске создаются
таблицы `sources` и `trackings`. Старая схема БД не поддерживается и не
мигрируется.
